# 开发日志 2026-09-04

## 今日完成
- 修复「每日」里他的状态标签不出现的问题（v1.5.3，未提交）：
  - 原因一：今天这条记录如果之前已经存在（如导入产生的空记录），程序只在"创建新记录"时生成他的标签，已存在的空记录不会补 → 改为：打开每日页时，今天已有记录但标签为空就自动补一个随机标签并存入数据库；与用户自己是否记录完全无关
  - 原因二：昨天打开过网站但没有打开「每日」页，昨天的记录根本没被创建；而程序对"已过去的日子"一律不生成标签 → 改为**按"你来没来过"补录**：
    - 新增 `src/utils/activeDays.ts`：`markTodayActive()` 每次打开网站记一笔"今天来过"（存 settings.activeDates，最多保留 60 天）；`getActiveDatesInRange()` 统计日期范围内你来过的日子（打开网站记录 + 当天有聊天消息/陪伴计时/写过的信；系统来信不算）
    - `App.tsx` 打开时调用 `markTodayActive()`
    - `dailyStore.loadMonth`：你来过的过去日子也会生成他的标签（立即显示），从没来过的日子不生成；过去日子已有记录但标签为空且你来过 → 补上
  - 揭晓时间：今天随机 0~6 小时、最晚不跨天（不超过当天 23:59）
- 「清理历史脏标签」按钮升级：你来过的日子他的状态是合理的，不清；只清你从没来过的日子的标签（仍必须先统计数量再手动确认）
- 来过记录随云备份整库打包自动备份/恢复，无需单独处理（用户要求"支持云备份里的导入导出"）
